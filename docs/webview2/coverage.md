# Покрытие интерфейса и проверок

Проверено 28 сентября 2026 года. Исходники OBS 33.0.0-beta4; личная установленная версия для сравнения — 32.2.1. Полный исходный перечень: [baseline-inventory.json](baseline-inventory.json). Он содержит 36 форм, 102 действия главного окна и 99 функций frontend API; это не число независимо испытанных сценариев.

## Проверенные результаты

- Настоящий portable OBS: **163/163**, завершение с кодом 0. Включены capture-размеры всех семи проверенных диалогов, проверка записи и сохранение fixture.
- Полный повторный запуск: **23 проверки в отчёте**, native state восстановлено без различий; дополнительная проверка записи самого отчёта также проходит.
- Native dialog bridge: **48 проверок**. Включены настоящие Qt-модели, делегаты, F2/Enter/Escape, QObject invalidation, palette/font, AbsoluteSlider, dock lifecycle и полностью нативная область.
- Браузерные действия проверены отдельно от native integration: ввод/blur, combo, число 854, checkbox, model edit, кнопки, right-click rename, перемещение и изменение ширины панелей, reload/persistence; ошибок JavaScript не зафиксировано.
- Диагностика нашла controller 100×30 при HWND 981×730; отложенная синхронизация после Qt Show/Resize исправила это. Финальный реальный CapturePreview имеет полный размер окна.

Локальные полные отчёты и изображения сохраняются в `.superpowers/sdd/2026-09-28-webview2-functional-parity/` и тестовом portable config. В Git входят тесты, а не личные настройки и записи.

## Известные границы

- Интерфейс гибридный: GPU, Qt popup menus, OS pickers и custom/native islands перечислены в [README.md](README.md). Qt не удалён; ссылка на старое окно сама по себе не считается переносом функции.
- Полный набор сторонних DLL пользователя под OBS 33 не запускался. Сохранены Qt/frontend API и исходные механизмы загрузки, но бинарная совместимость с установленным OBS 32 требует проверки конкретных версий плагинов.
- Live stream, replay buffer, virtual camera в принимающем приложении, все устройства захвата, VST, HDR, смена мониторов с разным DPI и производительность всей системы не проходили полную практическую матрицу. Для них сохранены исходные реализации; успешная локальная запись не доказывает весь этот набор.
- Вход Twitch/YouTube/Restream требует собственных OAuth-параметров форка. Официальные секреты OBS в исходниках отсутствуют.
- Remux, import/export, wizard и остальные редкие инструменты доступны через исходные actions и общий renderer; отдельный end-to-end сценарий каждого инструмента ещё не выполнялся.
- Physical Explorer→WebView2 file drop не проверялся мышью. Native/COM и JS проверки не следует выдавать за такую проверку.
- CapturePreview отображает HTML, но не вложенный native GPU/custom HWND. Полностью пустая область на таком PNG не доказывает отсутствие native preview на экране.
- На повторно используемых тестовых сценах OBS сообщает одну неосвобождённую аллокацию; контрольный Qt-only запуск ранее показывал ту же величину. Причина не локализована.
- Новые вспомогательные подписи пока русские; штатные строки приходят из текущей локализации OBS. Меню HTML временно скрывает native preview, чтобы HWND не перекрывал меню.

## Сохранность личной установки

Тесты и нормальная сборка используют отдельный portable-каталог. Личная установка, процессы, профили и коллекции сцен не заменялись. С исходными хешами совпадают все проверенные личные профили/коллекции/основные настройки. Четыре отличающихся файла из полного набора 22 относятся к cache/browser preferences и каталогу rtmp-services активной личной установки; они не копировались и не восстанавливались инструментами этой задачи.
